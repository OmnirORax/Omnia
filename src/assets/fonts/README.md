# Bundled electric-style font

Rubik Glitch Regular, by NaN and Luke Prowse, is provided under the SIL Open Font License 1.1. The complete license and copyright notice are in [OFL-RubikGlitch.txt](../../../public/fonts/OFL-RubikGlitch.txt).

Source: https://github.com/google/fonts/tree/main/ofl/rubikglitch

`RubikGlitch-Regular.woff` contains the original font's glyphs, converted from its TTF to WOFF for local browser delivery. No external font service is required at runtime. Missing characters fall back to the system font. The font changes presentation only; the Lightning animation is a separate VFX setting.
